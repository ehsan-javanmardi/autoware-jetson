# Layouts

Foxglove layouts are exported from the app: **Layout menu → Export layout**, saved here,
and committed so everyone opens the same panels.

Import with **Layout menu → Import layout**.

Keep one layout per job rather than one that does everything — a driving layout wants 3D,
speed and route; a perception-debugging layout wants object lists and the raw cloud, which
is in the `heavy` topic group and off by default.
